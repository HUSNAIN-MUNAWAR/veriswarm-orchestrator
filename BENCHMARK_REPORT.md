# Benchmark report

The included fixture benchmark compares four execution strategies over a common seeded order-service task set. It reports strict success, verification success, review burden, tool-call proxy, and recovery. Results are generated by `npm run benchmark`; no held-out qualification result is hard-coded.

Small fixture results are for engineering validation only. Qualification is marked inconclusive when the requested reliability target cannot be supported by the configured sample and one-sided bound.
