# Blockers and truth conditions

The repository and control plane are functional, but the following boundaries remain explicit:

- **Mock evidence only for committed media:** the screenshots, GIF, MP4, and capture manifest were generated by Playwright against `MockAgentProvider` and the seeded order-service fixture.
- **Live Codex qualification pending:** the `@openai/codex-sdk` adapter is real, but no successful live Codex run is claimed without a configured authenticated runtime and isolated workspace.
- **Held-out qualification pending:** the benchmark now executes real isolated development runs, but seven distinct held-out task families are declared `NOT EVALUATED` until their fixtures and executable contracts exist.
- **Parallelism boundary:** parallel-adjudicated has two distinct reviewer roles in the DAG, but the local scheduler currently executes ready tasks sequentially; it is not a concurrency result.
- **Development persistence profile:** the shipped server uses a durable file store and in-process scheduler. PostgreSQL, Redis, identity, multi-tenancy, and OpenTelemetry exporters are not production deployments.
- **Evaluator scope:** the TypeScript benchmark harness is reproducible for the fixture. The optional Python/FastAPI evaluator and any CRM-Agent-Bench result are not claimed.
- **Hosting scope:** the GitHub repository is available at the configured remote, but no public application deployment URL is claimed. The supported demo URL is local: `http://localhost:4317`.

These conditions are surfaced in the UI's provider/truth banner and in the README instead of being hidden behind simulated success.
